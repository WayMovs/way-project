# WAY Chechen Names Pack V01

Статус: `RESEARCH DATASET / HUMAN REVIEW REQUIRED / NOT AN OFFICIAL REGISTER`  
Дата сборки: `2026-07-21`

Начальный пакет чеченских личных имён для WAY и Codex. Пакет содержит женские и мужские формы, старые записи, варианты написания и шесть языковых представлений: чеченский, русский, английский, немецкий, турецкий и арабский.

## Состав

- 98 курируемых концептов: 53 женских и 45 мужских;
- 703 языковые/письменные формы;
- 181 историческая женская пара и 208 мужских пар из справочника 1987 года;
- 143 явных отношения между вариантами;
- 34 негативные пары против ложного слияния;
- код безопасной нормализации и правила для Codex.

`WAY_CHECHEN_NAMES_CODEX_BUNDLE_V01.md` содержит весь компактный корпус в одном читаемом файле. CSV-файлы предназначены для импорта и проверки.

## Жёсткие правила

1. Никогда не объединять профили людей по одному имени.
2. Всегда хранить исходное и документальное написание.
3. Нормализация используется только для поиска.
4. `Ӏ`, `1`, латинская `I` и строчная `ӏ` могут обозначать палочку, но оригинал не переписывается.
5. Не склеивать `х/хь/хӀ`, `к/къ/кх/кӀ`, `г/гӀ`, `ч/чӀ`, `ц/цӀ`.
6. Турецкие и арабские формы могут быть родственными по происхождению, но не равны автоматически документальному имени.
7. Английская и немецкая формы — поисковое/интерфейсное отображение, а не юридический перевод.
8. Пакет не считается полным и не является основанием определять национальность, пол, родство или личность.

## Источники и пределы достоверности

Основа — отдельные русская и чеченская колонки в *Справочнике личных имен народов РСФСР* (1987). Историческая запись не считается автоматически современной нормативной. Современные чеченские формы должны пройти проверку носителями языка и редакторами по действующим орфографическим правилам. Библиография и ограничения приведены в `sources/SOURCES.md`.

## Инструкция Codex

Использовать точное совпадение первым. Затем применять только безопасную техническую нормализацию. Явные отношения из `variant_relations.csv` показывать как объяснимые кандидаты. Нечёткое совпадение не является фактом. Политика для каждого результата: `NEVER_AUTOMATIC_PERSON_MERGE`.
